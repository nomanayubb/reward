# Snake

Original HTML5 snake game using the platform Game SDK.

## Gameplay

- 20×20 grid; the snake moves continuously
- Eat food to grow and score +1
- Ends on wall or self collision, or when the 90-second timer runs out
- Controls: arrow keys / WASD, or swipe on touch devices

## Running it

- Platform: open `/play/snake/` while logged in
- Standalone: open `game.html` (offline mode, no rewards)
