# Memory Match

Original HTML5 memory game using the platform Game SDK.

## Gameplay

- 4×4 board, 8 pairs of symbols
- Flip two cards per move; matched pairs stay open
- Score = 100 per pair − 10 per extra move (moves beyond 8)
- Ends when all pairs are found

## Running it

- Platform: open `/play/memory-match/` while logged in
- Standalone: open `game.html` (offline mode, no rewards)
